# DARKSHELTER

Analog Photography · Darkroom · Workshops

Website project for Grigoris, based on the original analog photography studio prototype.

## Current state

- `index.html` is the working static prototype with DARKSHELTER branding.
- `reference/original.html` preserves the original supplied HTML unchanged.
- No dependencies, installation or build step are required.
- The current public preview is https://analog-studio-pehtis.johnstaf.chatgpt.site/ . This repository is not yet connected to automatic deployment; GitHub commits do not update that preview.

## Preview locally

Run `python3 -m http.server 8080` from the repository root, then open http://localhost:8080/ .

## Before a business launch

The current page is a prototype. Images, pricing, workshop dates, availability, address and studio information contain placeholders. Enquiry and booking forms do not send messages or save reservations.

- Confirm the studio name with Grigoris and check name/domain availability.
- Add approved photographs with recorded usage rights; do not present stock or generated images as Grigoris's own work.
- Confirm actual services, camera inventory, contact information, prices and workshop dates.
- Connect enquiry forms to a real delivery service and verify receipt. Introduce payments or live availability only if requested.
- Review Greek/English copy, mobile/desktop layouts, accessibility and the real enquiry journey.
- Choose the production domain and connect deployment deliberately.
